<h1 align="center">Text Expander</h1>

<p align="center"><strong>Короткая аббревиатура — готовая фраза в нужном окне.</strong></p>

<p align="center"><a href="README.en.md">English</a> · <a href="https://github.com/Frommer-droid/Text_expander/releases/latest">Скачать последнюю версию</a></p>

Text Expander для Windows заменяет сокращения часто используемыми текстами: ответами, адресами и шаблонами писем. Например, `.mail` и пробел превращаются в `user@example.com`.

## Что умеет

- Организовывать сниппеты по категориям и подкатегориям, включать отдельные записи или целые группы.
- Вставлять текст по скан-кодам клавиатуры — независимо от активной раскладки.
- Ограничивать сниппет или категорию заголовком и классом нужного окна.
- Работать в трее, ставить подстановки на паузу, запускаться вместе с Windows и открываться свёрнутым.
- Импортировать и экспортировать сниппеты, настройки или общую резервную копию в JSON.
- Подстраивать тёмный интерфейс OneDark Pro под масштаб экрана или вручную корректировать его.

## Быстрый старт

Требуется Windows 10 или 11. Интерфейс приложения — на русском языке.

1. Скачайте установщик на [странице последней версии](https://github.com/Frommer-droid/Text_expander/releases/latest) и запустите его.
2. Подтвердите запрос Windows на запуск от имени администратора.
3. Нажмите **Новая категория**, затем **Новый сниппет**.
4. Введите аббревиатуру `.mail` и текст `user@example.com`, затем нажмите **Сохранить**.
5. В Блокноте напечатайте `.mail` и нажмите пробел — появится адрес.

Portable-вариант запускается через `Text_expander.exe` из распакованной папки вместе с `_internal` и остальными файлами. Python для него не нужен.

## Работа с приложением

В блоке **Фильтр по окну** можно указать заголовок и класс окна, а затем выбрать точное совпадение или поиск подстроки. Фильтр категории задаётся через её контекстное меню и наследуется сниппетами без собственного фильтра.

В меню трея доступны пауза, обновление сниппетов, автозапуск и выход. Левый клик по крестику завершает приложение, правый скрывает его в трей. Настройки масштаба, автозапуска и обмена данными находятся на вкладке **Система**.

Импорт JSON **заменяет текущие данные** выбранного типа. Перед импортом сохраните резервную копию через **Экспорт всего**.

## Данные и ограничения

Сниппеты (`snippets.json`), настройки (`expander_settings.json`) и журнал (`Text_expander.log`) хранятся рядом с приложением; папка должна быть доступна для записи. Эти файлы не входят в Git. Новая публичная сборка получает пустые сниппеты и отключённый автозапуск.

Приложение использует глобальный перехват клавиатуры и запускается с повышенными правами. Вставка выполняется через буфер обмена; его прежний текст восстанавливается, если его удалось прочитать. Другие менеджеры буфера обмена могут мешать вставке. Выбирайте заметный префикс сокращений, чтобы избежать случайных замен.

## Запуск из исходников

Установите Python 3.12 и Git, затем выполните:

```powershell
git clone https://github.com/Frommer-droid/Text_expander.git
cd Text_expander
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Start-Process .\.venv\Scripts\pythonw.exe -ArgumentList ".\Text_expander.pyw"
```

Для разработки:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest
```

[Руководство разработчика](DEVELOPER.md) описывает архитектуру и подготовку сборки. [История изменений](RELEASE_NOTES.md) содержит сведения о выпущенных версиях.
