# История изменений (Release Notes)

## Версия 5.18.0 (2026-09-15)

*Обновлённое оформление, предсказуемый выбор сниппетов и устойчивое закрытие приложения.*

### ✨ Новые возможности
- Новая иконка приложения и единый набор компактных иконок действий; рисунок заполняет весь доступный размер.
- Управление списком перестроено в два ряда с одинаковой высотой кнопок и короткой кнопкой «Сохранить».
- Статус прав администратора перенесён в верхнюю строку, а вкладка «О программе» удалена.

### 🐛 Исправления ошибок
- Предпросмотр больше не меняется от простого наведения курсора на другой сниппет: выбор меняется только после клика или клавиатурного подтверждения.
- Нажатие на крестик корректно завершает процесс приложения, а не оставляет его в Диспетчере задач.
- Исправлены выравнивание и фон иконок/чекбоксов, боковые отступы дерева и поведение разделителя при изменении ширины.

### 🛠 Улучшения
- При первом запуске окно открывается с рабочим размером и не сжимает элементы интерфейса.
- PyInstaller-сборка блокируется при DLL из недоверенных источников; перед упаковкой проверяются TOC, MSVC runtime и frozen smoke-test.

## Версия 5.17.0 (2026-09-14)

*Тема интерфейса OneDark Pro и сворачиваемый блок фильтра по окну.*

### ✨ Новые возможности
- Блок «Фильтр по окну» в редакторе сниппетов можно свернуть кнопкой-заголовком со стрелкой; состояние сохраняется в настройках и входит в экспорт/импорт.

### 🛠 Улучшения
- Интерфейс переведён на тёмную тему OneDark Pro: согласованные цвета фона, текста, кнопок и акцентов во всех вкладках, меню и диалогах.

## Версия 5.16.0 (2026-08-16)

*Лицензирование релиза, исключение неиспользуемого Qt runtime и тихий запуск в трей.*

### 🐛 Исправления ошибок
- При автозапуске и запуске свернутым больше не показывается всплывающее уведомление «Приложение запущено и свернуто в трей»: программа стартует в трей без лишних сообщений.

### 🛠 Улучшения
- Добавлены MIT-лицензия проекта, third-party notices и тексты лицензий для runtime-зависимостей и установщика.
- Сборка исключает неиспользуемый Qt Virtual Keyboard/QML/Quick runtime и блокирует установщик при наличии GPL-only Qt Virtual Keyboard файлов.
- Установщик Inno Setup включает текст лицензии проекта.
- Обновлены README и документация разработчика по лицензированию релиза.

## Версия 5.15.0 (2026-04-30)

*Масштабирование интерфейса, импорт/экспорт данных и улучшения запуска.*

### ✨ Новые возможности
- Добавлен масштаб интерфейса на вкладке `Система`: авто-расчет от экрана и DPI плюс ручная поправка пользователя.
- Добавлен импорт и экспорт сниппетов, настроек и общего backup JSON.
- Настройки масштаба сохраняются в `expander_settings.json` и входят в экспорт настроек.

### 🐛 Исправления ошибок
- Dev-запуск `.pyw` через `python.exe` теперь автоматически перезапускается через `pythonw.exe`, чтобы не оставлять консольное окно.
- Автозапуск в dev-режиме создает ярлык на `pythonw.exe` с корректными аргументами и рабочей папкой.

### 🛠 Улучшения
- Подключена русская локализация стандартных Qt-диалогов и меню.
- Настройки и backup JSON валидируются перед импортом и записываются атомарно.
- Добавлены тесты для путей, автозапуска, импорта/экспорта, формул масштаба и масштабируемой QSS-темы.
- Обновлена документация разработки, README и правила игнорирования runtime/build-файлов.

## Версия 5.13.0 (2025-12-21)

*Фильтрация сниппетов по окнам и новые режимы сопоставления.*

### ✨ Новые возможности
- **Фильтрация по окнам**: Привязка сниппетов к определённым приложениям по заголовку или классу окна Windows.
- **Настройка фильтра категории**: ПКМ на категорию → «Настроить фильтр окна...» — все сниппеты в категории наследуют этот фильтр.
- **Захват окна**: Кнопка «🎯 Захватить текущее окно» с 3-секундным таймером для удобного выбора целевого приложения.
- **Режимы сопоставления**: Поддержка «содержит» (contains) и «точное совпадение» (exact) для фильтров.

### 🛠 Улучшения
- Расширено контекстное меню категорий.

## Версия 5.12.0 (2025-12-19)

*Транслитерация аббревиатур и улучшения трея.*

### ✨ Новые возможности
- **Транслитерация аббревиатур**: Теперь можно вводить аббревиатуры латиницей, даже если они сохранены кириллицей (например, `.vv` -> `.вв`).
- **Системный трей**: Чекбокс «Автозапуск» добавлен прямо в меню трея.

### 🐛 Исправления ошибок
- **Слушатель клавиатуры**: Исправлена ситуация, когда после автозапуска разворачивание сниппетов начинало работать только после ручного перезапуска приложения.
- **Стабильность вставки**: Исправлено «залипание» режима замены при ошибках работы с буфером обмена.

### 🛠 Улучшения
- **Логирование**: `Text_expander.log` теперь перезаписывается на каждом запуске (хранится только текущий запуск).
- **Системный трей**: Пункт «Перезагрузить сниппеты» переименован в «Обновить сниппеты».
- **Системный трей**: Убран пункт «Перезапустить слушатель».
